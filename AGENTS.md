# Обновление обработки

Каждое изменение модуля сохраняется в ветке `development/yandex-kit` отдельным коммитом с номером версии и описанием пользовательского эффекта. Перед подготовкой сборки проверить последний commit ветки и версию исходной EPF, чтобы сохранить чужие изменения.

1. После сборки выполнить `python3 tools/export.py /путь/к/обработке.epf` и `python3 tools/index.py`. Сверить изменения BSL, привязок формы, XML и страниц команд. При новой команде дополнить её описание в генераторе и README.
2. Обновить описание поведения и результаты проверок. Отдельно отметить выполненные проверки структуры, запуск в 1С и реальные операции с КИТ.
3. Проверить diff на ключи, пароли, персональные данные и журналы. Рабочую EPF с ключами оставить в закрытом канале выдачи. Сохранить исходники, документацию и проверяемые изменения в одном коммите версии.
4. Отправить commit в ветку разработки и сверить SHA удалённой вершины. В ответе дать ссылку на commit, сборку и результаты проверки. Если GitHub недоступен, сохранить commit локально и явно указать, что отправка ещё не выполнена.
