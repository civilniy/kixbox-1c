# Получить KIT ID

Принимает один или несколько ШК. Пустой ввод выбирает все ШК КИТ. После общего подтверждения читает страницы вариантов по полю barcode, проверяет однозначность ID и затем ищет характеристику в 1С. Каждая запись выполняется в отдельной транзакции. Проверяет прежнее имя и новое значение до фиксации транзакции.

[ПолучитьКитИДНажатие](../../src/Module.bsl#L6803-L6851)

## Код обработчика

```bsl
Процедура ПолучитьКитИДНажатие(Элемент) Экспорт
    Если Сайт <> Перечисления.СписокСайтов.ЯндексКИТ Тогда
        Предупреждение("Выберите сайт Яндекс Kixbox.ru.");
        Возврат;
    КонецЕсли;
    Ввод = "";
    Если НЕ ВвестиСтроку(Ввод, "Получить KIT ID: введите штрихкоды через запятую или с новой строки. Пусто — все ШК из КИТ.", 0, Истина) Тогда
        Возврат;
    КонецЕсли;
    Попытка
        Коды = РазобратьШтрихкодыКИТ(Ввод);
        Если Коды.Количество() = 0 И СтрДлина(Ввод) > 0 Тогда
            Предупреждение("Введены только разделители. Для всех ШК очистите поле.");
            Возврат;
        КонецЕсли;
        Объем = ?(Коды.Количество() = 0, "всех штрихкодов из КИТ", "выбранных штрихкодов (" + Строка(Коды.Количество()) + ")");
        Если Вопрос("Получить и записать KIT ID для " + Объем + "?", РежимДиалогаВопрос.ДаНет) <> КодВозвратаДиалога.Да Тогда
            Возврат;
        КонецЕсли;
        Варианты = ПрочитатьИДПоШтрихкодамКИТ(Коды);
        Записано = 0;
        Совпало = 0;
        Ошибок = 0;
        Для Каждого Пара Из Варианты Цикл
            ШК = Пара.Ключ;
            Если Пара.Значение.Количество() = 0 Тогда
                Сообщить("ШК " + ШК + ": отсутствует в КИТ.");
            ИначеЕсли Пара.Значение.Количество() > 1 Тогда
                Сообщить("ШК " + ШК + ": в КИТ несколько ID варианта. Запись пропущена.");
            Иначе
                Попытка
                    Итог = ЗаписатьИДВариантаКИТ(ШК, Пара.Значение[0]);
                    Если Итог = "Записан" Тогда
                        Записано = Записано + 1;
                    ИначеЕсли Итог = "Совпадает" Тогда
                        Совпало = Совпало + 1;
                    КонецЕсли;
                Исключение
                    Ошибок = Ошибок + 1;
                    Сообщить("Получить KIT ID, ШК " + ШК + ": " + ОписаниеОшибки());
                КонецПопытки;
            КонецЕсли;
        КонецЦикла;
        Сообщить("KIT ID: записано " + Строка(Записано) + ", уже совпадало " + Строка(Совпало)
            + ", пропущено " + Строка(Варианты.Количество() - Записано - Совпало - Ошибок) + ", ошибок " + Строка(Ошибок));
    Исключение
        Сообщить("Получить KIT ID: " + ОписаниеОшибки());
    КонецПопытки;
КонецПроцедуры
```
