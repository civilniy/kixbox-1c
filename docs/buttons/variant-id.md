# Получить KIT ID

Для одного штрихкода проверяет товар и характеристику 1С и точное совпадение в КИТ. После подтверждения записывает UUID в свойство характеристики. Проверяет прежнее имя и новое значение до фиксации транзакции.

[ПолучитьКитИДНажатие](../../src/Module.bsl#L6740-L6766)

## Код обработчика

```bsl
Процедура ПолучитьКитИДНажатие(Элемент) Экспорт

    Если Сайт <> Перечисления.СписокСайтов.ЯндексКИТ Тогда
        Предупреждение("Выберите сайт Яндекс Kixbox.ru.");
        Возврат;
    КонецЕсли;
    ШК = "2700010662516";
    Если НЕ ВвестиСтроку(ШК, "Получить KIT ID для одной характеристики. Введите штрихкод:", 0, Ложь) Тогда
        Возврат;
    КонецЕсли;
    ШК = СокрЛП(ШК);
    Если ПустаяСтрока(ШК) Тогда
        Возврат;
    КонецЕсли;
    Для Индекс = 1 По СтрДлина(ШК) Цикл
        Если СтрНайти("0123456789", Сред(ШК, Индекс, 1)) = 0 Тогда
            Предупреждение("Введите один штрихкод цифрами.");
            Возврат;
        КонецЕсли;
    КонецЦикла;
    Попытка
        ПолучитьКитИДДляХарактеристики(ШК);
    Исключение
        Сообщить("Получить KIT ID, ШК " + ШК + ": " + ОписаниеОшибки());
    КонецПопытки;

КонецПроцедуры
```
