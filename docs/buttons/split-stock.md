# Товар по складам

Для введённых штрихкодов сравнивает доступное количество отдельно по каждому из девяти складов. Требует однозначного варианта, рассчитывает разницу, запрашивает подтверждение, отправляет пакет и повторно читает остатки.

[ТоварПоСкладамНажатие](../../src/Module.bsl#L6510-L6539)

## Код обработчика

```bsl
Процедура ТоварПоСкладамНажатие(Элемент) Экспорт
    Если Сайт <> Перечисления.СписокСайтов.ЯндексКИТ Тогда
        Предупреждение("Выберите сайт Яндекс Kixbox.ru.");
        Возврат;
    КонецЕсли;
    Ввод = "";
    Если НЕ ВвестиСтроку(Ввод, "Товар по складам: штрихкоды по одному в строке или через запятую", 0, Истина) Тогда
        Возврат;
    КонецЕсли;
    Попытка
        Ввод = СтрЗаменить(СтрЗаменить(СтрЗаменить(Ввод, Символы.ВК, " "), Символы.ПС, " "), Символы.Таб, " ");
        Ввод = СтрЗаменить(СтрЗаменить(Ввод, ",", " "), ";", " ");
        Коды = Новый Массив;
        Для Каждого ШК Из СтрРазделить(Ввод, " ", Ложь) Цикл
            Для Н = 1 По СтрДлина(ШК) Цикл
                Если Найти("0123456789", Сред(ШК, Н, 1)) = 0 Тогда
                    ВызватьИсключение "Некорректный штрихкод: " + ШК;
                КонецЕсли;
            КонецЦикла;
            Если Коды.Найти(ШК) = Неопределено Тогда
                Коды.Добавить(ШК);
            КонецЕсли;
        КонецЦикла;
        Если Коды.Количество() > 0 Тогда
            ПередатьРаздельныеОстаткиKIT(Коды);
        КонецЕсли;
    Исключение
        Сообщить("Товар по складам: " + ОписаниеОшибки());
    КонецПопытки;
КонецПроцедуры
```
