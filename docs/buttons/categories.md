# Выгрузить категории

В диалоге «Да» означает сверку с записью файла. «Нет» запускает сбор категорий по товарам с остатком, создание недостающих категорий, корректировку родителей и сверку.

[ВыгрузитьКатегорииНажатие](../../src/Module.bsl#L7309-L7352)

## Код обработчика

```bsl
Процедура ВыгрузитьКатегорииНажатие(Элемент) Экспорт
	
	Узел = ПолучитьНастройкиУзла(Сайт);
	
	Если Вопрос("Только сверка категорий с 1С?" + Символы.ПС + Символы.ПС
		+ "Да - ничего не создавать и не менять на сайте, только записать файл сверки." + Символы.ПС
		+ "Нет - выгрузить категории (создать недостающие, поправить родителей), затем сверка.", 
		РежимДиалогаВопрос.ДаНет) = КодВозвратаДиалога.Да Тогда
		ЗаписатьКатегории1СНаСайте(Узел);
		Возврат;
	КонецЕсли;
	
	СообщитьЭтап("Выгрузка категорий: сбор товаров с остатком...");
	
	Запрос = Новый Запрос;
	Запрос.Текст = "ВЫБРАТЬ РАЗЛИЧНЫЕ
	|	Ост.Номенклатура КАК Номенклатура
	|ИЗ
	|	РегистрНакопления.ОстаткиТоваров.Остатки(, Склад В (&Склады)) КАК Ост
	|ГДЕ
	|	Ост.ОстатокОстаток > 0";
	Запрос.УстановитьПараметр("Склады", Узел.Склады.ВыгрузитьКолонку("Склад"));
	Выборка = Запрос.Выполнить().Выбрать();
	
	ДеревоТоваров = Новый ДеревоЗначений;
	ДеревоТоваров.Колонки.Добавить("Номенклатура");
	Пока Выборка.Следующий() Цикл
		СтрокаТовара = ДеревоТоваров.Строки.Добавить();
		СтрокаТовара.Номенклатура = Выборка.Номенклатура;
	КонецЦикла;
	
	Категории = ПостроитьКатегорииПоТипу(ДеревоТоваров);
	СообщитьЭтап("Моделей: " + Формат(ДеревоТоваров.Строки.Количество(), "ЧН=0; ЧГ=0") 
		+ ", категорий: " + Формат(Категории.Количество, "ЧН=0; ЧГ=0") + ". Проверка и создание на сайте...");
	
	Если ВыгрузитьКатегорииНаСайт(Категории.Дерево, Узел) Тогда
		СообщитьЭтап("Категории выгружены. Карточки к ним привяжутся при выгрузке каталога.");
	Иначе
		СообщитьЭтап("Выгрузка категорий остановлена из-за ошибки, причина в сообщении выше.");
	КонецЕсли;
	
	ЗаписатьКатегории1СНаСайте(Узел);
	
КонецПроцедуры
```
