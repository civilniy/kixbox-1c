# Тест настроек

Создаёт настройки выбранного узла и проверяет соединение. Успешный ответ проверяет доступ к API, но ещё не проверяет запись цен, остатков или свойств.

[ТестНастроекНажатие](../../src/Module.bsl#L6497-L6508)

## Код обработчика

```bsl
Процедура ТестНастроекНажатие(Элемент)

	Узел = ПолучитьНастройкиУзла(Сайт);	
    ТестПройден = ВыполнитьТестПодключения(Узел);
	Если ТестПройден Тогда 
		Сообщить("Тест пройден!");
	Иначе
		Сообщить("Тест не пройден!");
	КонецЕсли;

	
КонецПроцедуры
```
