# Обновить остатки

Вызывает полный режим. Для основного сайта собирает девять складов, вычитает резерв и передаёт сумму на 106. Затем проверяет кандидатов на обнуление.

[ОбновитьОстаткиНажатие](../../src/Module.bsl#L7430-L7434)

## Код обработчика

```bsl
Процедура ОбновитьОстаткиНажатие(Элемент) Экспорт 
	Узел = ПолучитьНастройкиУзла(Сайт);
	ВыгрузитьОстаткиНаСайт(Узел, Истина);

КонецПроцедуры
```
