# Загрузить заказы

Показывает предупреждение Garage Sale и читает страницы заказов. Для подходящих новых заказов вызывает заполнение заказа покупателя. Путь может записывать и проводить документы, создавать заявки и файлы для печати.

[ЗагрузитьЗаказыНажатие](../../src/Module.bsl#L7436-L7458)

## Код обработчика

```bsl
Процедура ЗагрузитьЗаказыНажатие(Элемент) Экспорт      
	//ВНИМАНИЕ: загрузка заказов настроена под Garage Sale (префикс НКБ, организация Спейс Джем, склад 102).
	//Для приема заказов new.kixbox.ru эти настройки не подходят - кнопку не использовать.
	Ответ = Вопрос("Загрузка заказов настроена под GARAGE SALE:" + Символы.ПС
		+ "префикс НКБ, организация Спейс Джем, склад 102." + Символы.ПС + Символы.ПС
		+ "Для new.kixbox.ru эту кнопку НЕ нажимать." + Символы.ПС + Символы.ПС
		+ "Всё равно загрузить заказы?", РежимДиалогаВопрос.ДаНет, , КодВозвратаДиалога.Нет, "Заказы Garage Sale");
	Если Ответ <> КодВозвратаДиалога.Да Тогда
		Возврат;
	КонецЕсли;
	
	Узел = ПолучитьНастройкиУзла(Сайт);
	СписокЗаказов = ПолучитьСписокПоследнихОбновленныхЗаказов_chunks(Узел);
	
	Если НЕ СписокЗаказов.Количество() Тогда
		Возврат;
	КонецЕсли;
	
		
	ОбработатьЗаказыССайта(СписокЗаказов, Узел);

	// Вставить содержимое обработчика.
КонецПроцедуры
```
