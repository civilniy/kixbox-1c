# Выгрузить каталог

Принимает список штрихкодов или явное подтверждение полной выгрузки. Формирует отбор, передаёт категории и варианты, для основного сайта запускает цены. В пробном режиме сверяет категории и пишет результаты проверки ID.

[ВыгрузитьКаталогНажатие](../../src/Module.bsl#L6914-L6991)

## Код обработчика

```bsl
Процедура ВыгрузитьКаталогНажатие(Элемент) Экспорт
	
	Узел = ПолучитьНастройкиУзла(Сайт);
	
	ТекстШтрихкодов = "";
	Если НЕ ВвестиСтроку(ТекстШтрихкодов, "Штрихкоды для пробной выгрузки, по одному в строке или через запятую (пусто - весь каталог)", 0, Истина) Тогда
		Возврат;
	КонецЕсли;
	
	СписокШтрихкодов = Новый СписокЗначений;
	Текст = ТекстШтрихкодов;
	//любые разделители (перенос строки, запятая, точка с запятой, табуляция) -> пробел
	Текст = СтрЗаменить(Текст, Символы.ВК, " ");
	Текст = СтрЗаменить(Текст, Символы.ПС, " ");
	Текст = СтрЗаменить(Текст, Символы.Таб, " ");
	Текст = СтрЗаменить(Текст, ",", " ");
	Текст = СтрЗаменить(Текст, ";", " ");
	Для Каждого Часть Из СтрРазделить(Текст, " ", Ложь) Цикл
		//оставляем только цифры: при копировании могут попасть звездочки, кавычки, точки
		Штрихкод = "";
		Для Н = 1 По СтрДлина(Часть) Цикл
			Символ = Сред(Часть, Н, 1);
			Если СтрНайти("0123456789", Символ) > 0 Тогда
				Штрихкод = Штрихкод + Символ;
			КонецЕсли;
		КонецЦикла;
		Если НЕ ПустаяСтрока(Штрихкод) И СписокШтрихкодов.НайтиПоЗначению(Штрихкод) = Неопределено Тогда
			СписокШтрихкодов.Добавить(Штрихкод);
			Сообщить("Штрихкод для пробной выгрузки: " + Штрихкод);
		КонецЕсли;
	КонецЦикла;
	
	Если СписокШтрихкодов.Количество() > 0 Тогда
		НастройкиОтбора = Узел.ОтборНоменклатуры.Получить();
		ЭлементОтбора = НастройкиОтбора.Отбор.Элементы.Добавить(Тип("ЭлементОтбораКомпоновкиДанных"));
		ЭлементОтбора.ЛевоеЗначение = Новый ПолеКомпоновкиДанных("Штрихкод");
		ЭлементОтбора.ВидСравнения = ВидСравненияКомпоновкиДанных.ВСписке;
		ЭлементОтбора.ПравоеЗначение = СписокШтрихкодов;
		ЭлементОтбора.Использование = Истина;
		Узел.ОтборНоменклатуры = Новый ХранилищеЗначения(НастройкиОтбора);
		Узел.Вставить("ПоказатьОтправку", Истина);
		Узел.Вставить("ШтрихкодыПробнойВыгрузки", СписокШтрихкодов);
        Если Узел.Свойство("СкладСкидок") Тогда
            Узел.Вставить("ПолученныеИДВариантов", Новый Соответствие);
            Узел.Вставить("ФайлыОтправкиKIT", Новый Массив);
            Сообщить("ПРОВЕРКА ID ВАРИАНТА KIT | v1.84.4 | выбранных штрихкодов: " + Строка(СписокШтрихкодов.Количество()));
        КонецЕсли;
		Сообщить("Пробная выгрузка: штрихкодов " + Формат(СписокШтрихкодов.Количество(), "ЧГ=0"));
		Сообщить("Тип операции: изменения (modification_upload), остальной каталог на сайте не затрагивается");
		Сообщить("Если в итоге отправлено меньше строк, чем штрихкодов, - части штрихкодов нет на складах выгрузки с остатком больше нуля");
	ИначеЕсли НЕ ПустаяСтрока(ТекстШтрихкодов) Тогда
		Сообщить("Штрихкоды не распознаны, выгрузка отменена");
		Возврат;
	Иначе
		Если Вопрос("Штрихкоды не указаны. Выгрузить ВЕСЬ каталог?", РежимДиалогаВопрос.ДаНет) <> КодВозвратаДиалога.Да Тогда
			Возврат;
		КонецЕсли;
	КонецЕсли;
	
    Попытка
        ВыгрузитьТоварыНаСайт(Узел, Ложь);
    Исключение
        ВывестиПроверкуИДВариантовKIT(Узел);
        ВызватьИсключение;
    КонецПопытки;
	
	Если СписокШтрихкодов.Количество() > 0 И НЕ Узел.Свойство("СкладСкидок") Тогда
		СообщитьЭтап("Пробная выгрузка цен для тех же штрихкодов...");
		ТаблицаЦен = ПолучитьТаблицуЦен(Узел);
		Если ТаблицаЦен.Строки.Количество() = 0 Тогда
			Сообщить("Цены: для этих штрихкодов нечего отправлять (нет остатка на складе или цены)");
		Иначе
			ОтправитьЦеныНаСайт(ТаблицаЦен, Узел, "price_update_" + ПолучитьТекущуюДатуTimeStamp());
		КонецЕсли;
	КонецЕсли;
	
    ВывестиПроверкуИДВариантовKIT(Узел);
КонецПроцедуры
```
