# Обновить цены

Запускает ценовую выборку для выбранного узла. Для основного сайта в расчёте участвует склад скидок 218. Отправка цен и обновление характеристики скидки — отдельные операции.

[ОбновитьЦеныНажатие](../../src/Module.bsl#L7217-L7220)

## Код обработчика

```bsl
Процедура ОбновитьЦеныНажатие(Элемент) Экспорт 
	Узел = ПолучитьНастройкиУзла(Сайт);
	ВыгрузитьЦеныНаСайт(Узел);
КонецПроцедуры
```
